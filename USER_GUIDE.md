# Homi – User Guide

Welcome to **Homi**, a simple and intuitive interior design app that lets you visualize and customize your dream room in 3D.  
You can browse furniture, create layouts, edit room dimensions, adjust wall colors, and explore your space in full 3D — all from your iOS device.

This guide will walk you through installing the app, creating your first layout, and using all of Homi’s features.

---

# Installing Homi

## **Option A — Running from Xcode**
Homi is currently distributed as a development build.

To install:

1. Install **Xcode 15+** from the macOS App Store  
2. Clone the repository:
   ```bash
   git clone https://github.com/connthi/Homi.git
   cd homi
   ```
3. Open:
   ```
   Homi/Frontend/Homi/Homi.xcodeproj
   ```
4. Connect an iPhone **or** choose a Simulator (iPhone 14/15 recommended)  
5. Press **Run (⌘ + R)** to install the app

The app will launch automatically on your device/simulator.

## INDEPTH GUIDE
1. Log into your account with Homi
    - Register or log into homi with your account
2. View our catalog using the catalog tab, to view our catalog of furniture
3. Create your first room layout!
    - You can change your wall paper on the walls
    - Adjust the dimensions of the room with a bar, or input your own dimensions
    - Drop in furniture in our catalog to start designing
        - Move it around anywhere you'd like
        - Rotate it at any angle you'd like
        - Scale the furniture if you'd like
    - If you want to take a closer look press on our in person view at the top
        - Allows you to see your room in first person
        - You can move around your created room
4. Save your layout to be able to come back to it or if your done!
5. You can view your saved layouts in our layout tab on the home page.
    - Allows you to see past layouts
    - Load previous layouts to keep working on it
    - Delete layouts if you are unhappy with it
    - Export your layout as an image to remember what your designed room looks like!

# How to File a Bug Report

If you experience a problem with Homi, please report it so the team can fix it quickly.

### Before Submitting a Bug
Please include:

- **Description of the issue**
- **Steps to reproduce**
- **Expected behavior**
- **What actually happened**
- **Screenshots** (if applicable)
- **Device model & iOS version**
- **Whether the issue appears on simulator, physical device, or both**

### How to File the Report

#### Option A — Create a GitHub Issue  
1. Visit the repository:
   ```
   https://github.com/connthi/Homi/issues
   ```
2. Click **New Issue**
3. Select **Bug Report**
4. Fill out the template  
5. Submit the report

#### Option B — Email the Team
If you cannot access GitHub:

Send an email to:

**ptang6@uw.edu**

Include the same information listed above.
